# 3-Statement Financial Model

A fully linked three-statement financial model built in Excel — Income Statement, Balance Sheet, and Cash Flow Statement, connected so a change in one flows through to the others automatically.

## What this project covers

- **Income Statement** — revenue build-up through to net income
- **Balance Sheet** — assets, liabilities, and equity, balancing correctly period over period
- **Cash Flow Statement** — derived from the Income Statement and Balance Sheet changes, not built independently
- **Full linkage** — no hardcoded numbers between statements; every figure traces back to a single driver or assumption

## Skills demonstrated

- Financial modeling logic (how the three statements connect)
- Formula-driven forecasting instead of static numbers
- Understanding of how net income flows into retained earnings, and how balance sheet changes drive the cash flow statement
- Assumption-based modeling (inputs clearly separated from calculations)
