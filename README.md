# 3-Statement Financial Model — Historical & Forecast (2018–2030)

A fully linked three-statement financial model built in Excel, covering five years of historical actuals (2018–2022) and an eight-year driver-based forecast (2023–2030). Income Statement, Balance Sheet, and Cash Flow Statement are fully integrated, so a change in any assumption flows through the entire model automatically.

## What this project covers

- **Historical analysis** — actual financials for 2018–2022 used to calculate real trend ratios (margins, growth rates, expense ratios) before assuming anything forward
- **Driver-based forecast** — projections built on explicit assumptions: sales growth rate, gross margin, SG&A as % of sales, depreciation as % of sales, interest as % of long-term debt, and effective tax rate
- **Full 3-statement linkage** — Income Statement drives the Balance Sheet and Cash Flow Statement; nothing is a standalone, disconnected number
- **Supporting schedules** — PPE roll-forward, retained earnings roll-forward, and working capital changes, each built out separately for transparency
- **Built-in balance check** — every year, 2018 through 2030, verified to confirm Total Assets equals Total Liabilities + Equity

## Skills demonstrated

- Financial modeling logic and full statement integration
- Driver-based forecasting (not hardcoded projections)
- Debugging a real balance sheet imbalance by tracing formula dependencies back to source
- Schedule-building (PPE, retained earnings, working capital) as supporting detail rather than buried formulas
